# TestPilot-RL

Intelligent Software Testing Using Reinforcement Learning.

## Objective

Develop a tabular Q-learning agent that learns to select
software test cases to discover unique hidden bugs under
a limited execution budget.

## Project Status

Day 1: Repository setup and simulator/environment development.

## Planned Components

- Synthetic test scenario generator
- Budget-constrained testing environment
- Tabular Q-learning agent
- Random and fixed-order baselines
- Training and evaluation pipeline
- Reproducible results and visualizations
